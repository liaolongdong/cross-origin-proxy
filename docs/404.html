为什么会落到这一页Why you ended up here

三种真实原因，都不是「网站坏了」。 Three real reasons, none of which means the site is broken.

  1. 地址差一个字符 / One character off 大小写、结尾的斜杠、.html 后缀都算不同的地址，静态目录不会替你猜。 Case, a trailing slash and the .html suffix all make a different address; a static directory will not guess for you.
  2. 两条中文旧路径已下线，且没有 301 / Two retired paths, no redirect /zh.html 与 /zh-alternatives.html 已分别合并到站点根与 alternatives.html。Pages 是纯静态目录、没有重写规则，所以旧链接不会被自动送到新地址， 只会落到这一页——请从上面那一组里重新挑一个。 /zh.html and /zh-alternatives.html were merged into the site root and alternatives.html. Pages serves a plain directory with no rewrite rules, so old links are not forwarded — pick a target above instead.
  3. 地址来自旧快照或 AI 回答 / From a stale snippet or an AI answer 本站现存页面的机器可读清单是 llms.txt（摘要）与 llms-full.txt（全文），照着取地址就不会再落到这里。 The machine-readable list of every live page is llms.txt (summary) and llms-full.txt (full text).
